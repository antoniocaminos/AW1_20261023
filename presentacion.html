LocalStorage y SessionStorage

Guardar datos en el navegador con Web Storage API

Duracion: 60 minutos

Pregunta para arrancar

Cuando cambias WhatsApp a tema oscuro y cerras el navegador...

Por que sigue oscuro cuando volves?

Donde se guarda esa preferencia?

Que es Web Storage API

El navegador tiene una caja de almacenamiento con dos cajones:

localStorage

Se guarda para siempre (hasta que lo borres)

sessionStorage

Se guarda solo mientras la pestana este abierta

Ambos guardan pares clave - valor como texto (string).

Comparativa completa

Caracteristica localStorage sessionStorage
Duracion Hasta borrar Solo la pestana
Compartir entre pestanas Si No
Al cerrar navegador Se mantiene Se borra
Capacidad 5 a 10 MB 5 MB
Tipo de datos Solo strings Solo strings

Cuando usar cada uno

localStorage

  • Tema oscuro / claro
  • Preferencias de usuario
  • Carrito persistente
  • "Recordarme"

sessionStorage

  • Borrador de un formulario
  • Datos temporales de un flujo
  • Carrito temporal (demo)
  • Estado de un wizard

Metodos (identicos en ambos)

// Guardar
localStorage.setItem("clave", "valor");

// Leer (devuelve string o null)
const valor = localStorage.getItem("clave");

// Eliminar una clave
localStorage.removeItem("clave");

// Borrar todo
localStorage.clear();

// Cuantos elementos hay
localStorage.length;

// Clave por indice
localStorage.key(0);

Regla de oro: todo es string

Los objetos NO se guardan directamente. Se convierten a texto.

// MAL: se guarda "[object Object]"
localStorage.setItem("usuario", { nombre: "Ana" });

// BIEN: convertir a JSON
localStorage.setItem("usuario", JSON.stringify({ nombre: "Ana" }));

// Al leer, volver a objeto
const usuario = JSON.parse(localStorage.getItem("usuario"));

Practica 1: Tema oscuro

Por que localStorage: el tema debe persistir aunque cierren el navegador.

// Al cargar la pagina, revisar tema guardado
const temaGuardado = localStorage.getItem("tema");
if (temaGuardado === "dark") {
  document.body.classList.add("dark");
}

// Al hacer clic, alternar y guardar
btn.addEventListener("click", () => {
  document.body.classList.toggle("dark");
  if (document.body.classList.contains("dark")) {
    localStorage.setItem("tema", "dark");
  } else {
    localStorage.setItem("tema", "light");
  }
});

Practica 2: Carrito

Por que sessionStorage: carrito temporal mientras navega, se borra al cerrar.

function obtenerCarrito() {
  const data = sessionStorage.getItem("carrito");
  return data ? JSON.parse(data) : [];
}

function guardarCarrito(carrito) {
  sessionStorage.setItem("carrito", JSON.stringify(carrito));
}

// Agregar producto
const carrito = obtenerCarrito();
carrito.push({ nombre: "Cafe", precio: 1500 });
guardarCarrito(carrito);

Errores comunes

Nunca guardar datos sensibles

Contrasenas, tokens, datos personales. Cualquiera los puede leer desde DevTools.

Olvidar el JSON.parse

Si guardaste un objeto, al leerlo te llega un string, no el objeto.

Confundir persistencia

Si guardas con sessionStorage y el usuario cierra la pestana, se pierde todo.

Ejercicio para resolver

Crear un input para el nombre del usuario.

  • Al hacer clic en "Guardar", guardar en localStorage.
  • Al recargar, mostrar "Hola, [nombre]" si existe.
  • Bonus: boton "Olvidar" que use removeItem.

Pista: getItem devuelve null si la clave no existe. Usalo para decidir si mostrar el saludo.

Resumen final

  • localStorage - datos que persisten (tema, preferencias, carrito largo plazo)
  • sessionStorage - datos temporales de una pestana (borradores, flujos)
  • Siempre JSON.stringify y JSON.parse para objetos
  • Nunca guardar datos sensibles
  • Ver todo en DevTools: pestana Application - Local / Session Storage
